# 🐆 Panther Intelligence Bot v3.0

An advanced **Cybersecurity Simulation & Utility Bot** built with Python. This tool demonstrates how automated scripts can simulate hacking scenarios and perform security tasks.

## 🔥 Features & Commands

### 💀 Offensive Simulation (Prank)
- `/hack` - Run System Breach Protocol (Simulation)
- `/ddos <url>` - Simulate a DDoS Attack on a target website (Prank)
- `/leak <email>` - Check for fake data breaches

### 🕵️‍♂️ Intelligence & Spying
- `/trace <number>` - Simulate Satellite Number Tracking
- `/fakeid` - Generate a realistic Fake Identity for testing
- `/ip` - Geo-Locate IP Address
- `/ff <uid>` - Extract Free Fire Gaming Profile

### 🔐 Security Tools (Real Utilities)
- `/encrypt <text>` - Encrypt a secret message (AES Logic)
- `/decrypt <code>` - Decrypt the secret code
- `/pass` - Generate a High-Security Strong Password
- `/scan <url>` - Detect Phishing & Malicious Links
- `/qr <url>` - Generate QR Matrix Code
